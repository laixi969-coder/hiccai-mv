# 镜头语言与场面调度

在首次编排完整 MV、单场景或修改摄影/剪辑方案时读取。目标是帮助选择值得观看的镜头，不是输出运镜百科。方法参考 Film Cinematography Master，并针对 MV 与生成提示词重新组织；来源和技术核对依据见 [来源说明](../THIRD_PARTY_NOTICES.md)。

## 1. 先决定观看体验

先在内部形成段落：观众从哪里看、首先注意什么、随后出现什么关系、音乐和表演如何推进。可以通过叙事信息，也可以通过轮廓、材质、身体、光线和节律组织段落。静止、重复与留白都是选择，不要求每镜新增事件。

需要选择方向时，比较少量相互不同的拍法，选择更适合素材、时间和全片气质的一种；不把候选全部交给用户审批，也不把所有技法混进成稿。

| 观看位置 | 适用的表达 | 提示词要说清的内容 |
|---|---|---|
| 与人物同行 | 身体节律、参与感、穿越空间 | 跟随的前后/侧面关系、距离变化、谁带动移动 |
| 外部观察 | 造型展示、群体关系、距离感或静观 | 人物占比、留白、遮挡与观看时长 |
| 人物主观 | 视线目标、感官变化、发现或误认 | 谁在看、看到什么、如何进入或离开主观视角 |
| 信息领先/滞后 | 期待、悬念、反差或揭示 | 观众与人物分别已知什么，何时显露关键对象 |
| 形式观看 | 材质、比例、重复、声画实验 | 视觉关系的变化或持续方式，不必另加故事事件 |

## 2. 技法选择与准确描述

下面是选择库，不要求一支片用齐。技术名称可辅助理解，最终必须能从自然语言看出画面变化。

| 技法 | 要区分的运动或光学关系 | 可服务的任务 |
|---|---|---|
| 推轨/拉轨 Dolly in/out | 摄影机接近/远离主体；位置变化带来空间关系与视差变化 | 靠近、退出、改变人物与环境的比例关系 |
| 变焦 Zoom | 机位固定、焦距变化，改变取景范围；不能当作摄影机穿越空间 | 强调、观察距离感、突发视觉节拍 |
| 摇摄 Pan / 俯仰 Tilt | 机位不平移，分别水平或竖向转动朝向 | 追随视线、显露关系、连接画面区域 |
| 横移 Truck / 跟拍 Follow | 前者描述机位横向位移，后者描述相对移动主体的跟随关系，可组合 | 展示侧面轮廓、产生前景视差、陪伴行动 |
| 升降 Boom / 摇臂 Crane | 机位高度变化；若路径有弧线或水平位移另写 | 改变尺度、揭示站位、从整体进入细节 |
| 环绕 Arc / Orbit | 指定绕谁、方向、幅度、结束角度及是否保持主体大小 | 展示服装体积、改变人物关系、空间实验 |
| 甩镜 Whip pan | 快速转向并产生短暂模糊，写方向、时点与落点 | 注意力跳转、节拍重音或跨镜衔接 |
| 稳定跟拍 / 手持感 | 描述平滑度、摆动幅度、频率及与人物动作的关系 | 漫游、贴近身体或紧迫感；手持不自动等于剧烈抖动 |
| 固定机位 | 摄影机保持位置与朝向，由表演、调度、声画或停留组织画面 | 凝视、群体几何、材质、反差与呼吸 |
| 焦点转移 Rack focus | 指定清晰对象 A 到 B、触发和时长；不是变焦或移动机位 | 在前后景之间转移注意力、延迟揭示 |
| 持续跟焦 | 随主体距离变化调整焦点，维持同一主体清晰；区别于 A/B 焦点转移 | 运动演唱、行走与近景表演 |
| 倾斜构图 Dutch angle | 水平线的倾斜状态；静态倾斜不等于摄影机持续翻滚 | 几何张力、失衡或图形构成，并非固定情绪符号 |
| 滑动变焦 Dolly zoom | 摄影机位移与反向变焦配合，使主体画面尺寸近似不变，背景比例关系改变 | 心理转折、尺度实验；需有背景纵深与清楚主体 |
| 急变焦 Crash zoom | 快速改变焦距，机位不因此前进；若同时位移需另写 | 突然强调、节奏反差、戏剧或幽默 |
| 长镜头 Long take | 指连续时间结构，不是单一运镜；可固定也可移动，允许依次完成多次调度 | 持续表演、空间探索、紧张积累或观看仪式 |
| 深焦/浅景深 | 决定哪些纵深层次清晰；不能把前后层次都清晰与强虚化同时要求在同一对象上 | 关系并置、选择性注意；全片不必都浅景深 |
| 航拍/高位视角 | 交代位置、高度变化和路径，不能只写设备名 | 群体尺度、地形、空间构成；无需要时不强加宏大开场 |

需要时间质感时，分开描述慢动作、单帧停留/重复造成的顿挫与曝光拖影；它们可以组合，但不是同义词。指定作用于哪个时段、人物还是环境，保留口型和动作可读性。没有核实平台控制能力时描述可见目标，不保证模型执行某种拍摄或后期工艺。

## 3. 先调度人物与空间，再安排摄影机

多人物或复杂场景内部确定：前/中/后景位置、相互视线、行动先后、遮挡关系、摄影机通路、关键变化后的站位。只写影响镜头的内容，不绘制无用全场地图。

- 固定镜头也能通过人物入画、退出、交叉、转身、重心或前后景关系变化形成发展。
- 人物越过摄影机、交换画面左右或越轴时，用可见移动、中性视角或重新建立空间说明关系；有意断裂可以保留，但不能无意换人或换持物手。
- 镜头可揭示已存在但被遮挡的对象；需要参考之外的新角色或道具时，先检查是否在允许的创作范围内。
- 长镜头依次安排注意力重点，明确何时跟谁、停在哪里、转向什么。路线能通过，演唱、行走和互动所需时间足够；不要在两秒内要求完成一组复杂空间事件。
- 时尚呈现关注服装轮廓在转身中的变化、身体与建筑线条、面料在运动和光线中的反馈；避免将人物调度降为每镜同样的摆手或走台。

## 4. 情绪与形式的候选拍法

这些是可试的方案，不是情绪公式。相同技法可产生不同感受，须结合内容、声音、距离和前后镜判断。

| 目标 | 可尝试的路径 | 另一种可行路径 |
|---|---|---|
| 亲近 | 同步行走、逐渐靠近、保留表情时间 | 固定近景，人物主动进入或离开观看距离 |
| 疏离 | 环境比例增加、后拉、留白 | 拥挤近景中阻断目光或让声音脱离现场 |
| 期待/紧张 | 限制信息、延迟揭示、缓慢逼近 | 固定宽景，让观众看见人物尚未发现的关系 |
| 力量/存在感 | 稳定站位、明确身体轮廓与视线 | 克制近景配声音重音，不依赖一律仰拍 |
| 失衡/陌生 | 有限的倾斜、空间比例或时间变化 | 保持摄影机稳定，让人物节律与环境不同步 |
| 释放/高潮 | 扩大行动范围、打开空间、加速 | 音乐最满处突然停住，延长一次凝视或动作余势 |
| 时尚形式实验 | 轮廓、材质与摄影方向贯穿段落 | 重复构图或动作，用一次差异改变观看预期 |

## 5. 导演风格作为创作入口

可使用上游提到的导演/摄影师方向启发构思。下表是面向本 Skill 的候选拍法，不是对其全部作品的事实概括，不声称导演始终如此拍摄。引用具体影片、镜头时长、发明归属或名言时另行核实；创作提示词不依赖这些历史断言。

| 参考方向 | 可提取为当前 MV 的选择 |
|---|---|
| 希区柯克方向 | 限制/提前提供信息，组织视线、对象和反应，按揭示时机移动摄影机 |
| 库布里克方向 | 几何秩序、纵深、受控速度及人物与大空间的关系 |
| 黑泽明方向 | 群体运动、不同纵深层的行动、风雨等环境节律与剪辑的配合 |
| 奥逊·威尔斯方向 | 前后景关系并置、机位高度与空间主次，不把深焦只当清晰度指标 |
| 斯科塞斯方向 | 行动带动空间穿行，音乐重音与移动/切镜形成节律 |
| 王家卫方向 | 遮挡与距离、时间质感、局部色彩和身体节奏；不指定颜色必然代表哪种情绪 |
| 韦斯·安德森方向 | 正面或横向组织、图形化站位、几何重复和突然转向 |
| 杜琪峰方向 | 群体站位、视线与空隙产生张力，固定机位中的空间变化 |
| 卡隆/卢贝兹基方向 | 连续空间中人物与环境共同调度，摄影机随注意力改变路径 |
| 芬奇方向 | 有动机、可描述的精确跟随与停顿，统一的空间和影像控制 |

选定主导观看语法后，可用相容的另一种方法制造反差；不要逐镜更换导演标签。最终把名字转换成具体构图、光线、运动、表演与声画关系。无需在每次输出中出现导演姓名或电影例子。

## 6. 镜头之间如何产生作用

相邻镜头可以延续，也可以中断：运动接静止可强调停顿，近景接远景可重置尺度，主观接反应可改变理解。判断观看体验和音乐位置，不预设某种组合一定无效。

连续性切镜检查动作、视线、方向与状态；图形匹配检查注意力落点、尺度及方向；有意反差检查情绪、声音或主题关系。不必所有转场都匹配所有变量。关键转场两端必须一致写明，普通切镜简洁处理。

声音可先进入下一空间或在切镜后延续。现场声应有场景依据；摄影机移动不意味着必须添加设备轮噪或操作员脚步。音乐卡点也不是每一拍都切镜，允许切在动作、歌词或停顿的表达位置。

## 7. 输出与修订

只把选定方案压缩成：时间、主体与画面、必要的调度/摄影、声音触发和衔接。观看动机通常通过具体画面体现，不逐镜附教学解释。固定镜头不编造路线，连续镜头不为覆盖技法而强行剪开。

若结果乏味，先检查观看距离、信息揭示、人物调度和段落节律；若过满，删去竞争动作、延长必要停留或合并镜头；若风格拼贴，统一观看语法与色光关系。保留已确认的时尚先锋方向和人物身份，再调整实现手法。
