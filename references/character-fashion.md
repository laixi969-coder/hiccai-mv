# 人物与时尚造型

用于 MV 中的人物设定、时尚呈现与连续性。涉及人物时在分镜前读取；不是独立写真或生图工作流。以下身份/妆容分层方法参考并适配自南鸢·人像角色设定师，来源及 MIT 声明见 [来源与许可范围](../THIRD_PARTY_NOTICES.md)。

用户明确要求 MV 人物参考图或生图提示词时，本文件管理身份与造型，同时遵循 [参考图资产与图像质量](reference-assets.md) 的成像、照明与视图规则。素材清晰度的调整不改变已锁定的身份、年龄、基础肤色或造型。

## 1. 先确定设计范围

| 当前任务 | 可设计的内容 | 必须保留的内容 |
|---|---|---|
| 已有参考人物进入 MV | 允许的新机位、表演、布光与构图 | 身份、基础肤色、已锁定的妆发服装；不可见特征不补造 |
| 用户要求原创 MV 人物 | 在用户约束内设计结构、妆发、服装与表演 | 已选年龄、外观和创意要求；确定后形成身份基线 |
| 同一人物局部换妆或造型 | 仅改指定维度，更新对应造型版本 | 其他身份、造型、表演和摄影设定 |
| 明确要求多位不同原创角色 | 在自由的结构和表演维度上建立区别 | 共用视觉风格和指定的同款妆容/服装 |

无年龄约束的原创写真人物按成年人设计，不自动限定为年轻女性或浅肤色。不从气质、文化背景或国籍推导唯一脸型；固定脸型不妨碍清冷、亲和或英气等不同表演方向。人物性格是创作设定，不能由真实人物的外貌推断。

既有参考只换拍法时，不自动新增实验妆、首饰或换装。允许重新设计造型时明确采用的变化，确定后在全片遵守。没有人物的项目跳过本模块。

## 2. 三层人物基线

| 层 | 最小有效记录 | 变化规则 |
|---|---|---|
| 身份 | 角色编号、主参考、主要轮廓与五官关系、基础肤色、指定辨识特征、不可确认项 | 固定人物不因审美、表情或机位变化重新设计 |
| 造型 | 妆容重点与材质、发型轮廓、服装廓形及面料、配饰位置和连接；必要时编号 Look A/B | 仅在允许的变化处切换，标明时间及相关镜头 |
| 镜头表现 | 视线、表情、肩颈、重心、动作阶段、透视、光源及运动造成的外观变化 | 可随叙事变化，必须与身份和造型基线相容 |

描述参考图时区分确定可见、受光线/角度影响的推测、无法确认。闭眼不能证明完整眼型，强侧光不能证明深眼窝，修容造成的阴影不能登记为骨骼凹陷。原稿没有写清的结构，局部修改时仍保持未知。

## 3. 原创人物的结构与气质

仅在允许原创结构时，决定整体长宽与局部比例，再组织眉骨/眼窝、颧部、下颌/下巴的关系，并选取有辨识作用的眼、鼻、唇和自然眉特征。区分横向宽度、前后突出和软组织体量，不将高颧位等同于宽脸，也不将尖下巴等同于前伸。

选定主气质，再用表演、妆容或造型补充次气质；不让所有部位同时强调。结构柔和也能通过姿态和摄影呈现利落感。避免无意识地把所有角色都补成同一套小脸、大眼、高鼻梁、尖下巴；用户明确选定这些特征时保留，不为了特别而强加瑕疵。

多位不同原创人物先比较轮廓比例、颧颌关系、眼部、鼻部、唇部与自然眉形，避免仅靠换发型、肤色和服装区分。只改变未锁定的维度，不给同一人物的不同造型执行“拉开脸型差异”。不把文字结构差异当作生成图可辨识度保证。

## 4. 将时尚表达落实到造型

先从全片视觉规则选择主导关系，例如线条延伸、体积对比、软硬反差或局部光泽。它应影响造型、姿态与拍摄；具体采用哪一种由素材和创意决定。

| 对象 | 可执行的设计信息 | MV 中的检查点 |
|---|---|---|
| 妆容 | 部位、色相、范围、线条方向、边缘、质地、强度 | 睁眼和转头时是否仍成立；是否与主光及特写任务相容 |
| 发型 | 分缝、轮廓、体积、长度、固定与松散区域 | 运动是否遮住眼睛/口型；返回镜头是否无故改长短与分缝 |
| 服装 | 肩腰比例、廓形、面料厚薄、垂坠/挺括及运动反馈 | 动作是否可完成；衣料褶皱和反光是否支持造型 |
| 配饰 | 尺度、材质、左右位置、佩戴及连接方式 | 遮挡后是否消失、复制或换边；是否干扰表演 |
| 身体表现 | 视线、肩颈、手部、重心、动作节律 | 姿态与人物气质有关系，不能所有角色都用同一套手势 |

妆容通常选一个视觉重点，其他区域配合；用户要求多重点实验妆时可以执行，但须给出层次。肤色、覆盖度与表面反光分开描述：清透不自动提白，局部湿亮不等于全脸油亮。没有需要时不自动加痣、雀斑、油脂或粗糙纹理。

固定妆容跨人物或跨镜头时，保留色彩关系、质地、线条方向及相对五官落点；不同脸允许适配覆盖面积。共同身份与妆容在全片基线定义，逐镜只写发生的变化。不得将哑光唇在后镜改成镜面唇并称为“同款妆”。

## 5. 让人物参与先锋机制与转场

在允许范围内，从人物已有的线条、廓形、材质或动作提取视觉关系，以变化、持续、重复或反差组织观看。重要镜头可以承担实验，其他镜头提供辨认人物和观看表演的时间。不要每镜发明一个互不相关的异常，也不强迫每个短镜头完成建立、变化与回应三步。

例如素材中已经存在斜线关系时，可以让眼妆走向、衣领斜切和手臂方向相互呼应，再把手臂落点接到下一场建筑斜线上。两端需写清画面位置、角度、尺度与注意力落点；这只是机制示例，不自动给每个项目添加图形妆、斜切服装或建筑。

先锋性也可以来自表演的停顿、画面比例或声画关系，无需每次改变人体或制造超现实物体。若采用镜像、重复或时间错位，写明它是影像表达还是世界内实际事件、影响哪些对象，以及身份、物件数量与接触关系如何保持可辨认。

## 6. 局部修订与交付

按“目标层 → 允许变化项 → 保留项 → 依赖镜头”修订。例如只换唇色，应保留唇形、边缘、光泽和其他造型；若原唇色承担颜色匹配转场，再更新那一处衔接。要求表情柔和，先调整表情及相关线条表现，不自动削骨、改眼型或改变肤色。

最终完整 MV 提示词中集中写人物基线和造型版本，各镜只增加相关状态。需要镜头近看才有意义的细节，不在所有远景反复堆写。已确认人物以参考映射和辨识特征为主，不重复生成一篇人像提示词。

交付前核对：身份与光影是否混淆、造型变化是否有依据、多个角色是否混用、实验是否破坏锁定项、局部修改是否波及无关内容。检查文字通过不等于图片或视频已验证；有实际成片后再核对可见偏差。
