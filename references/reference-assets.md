# 参考图资产与图像质量

用于用户明确请求的 MV 人物图、角色设定图、三视图、场景图及其生图提示词。人物身份与造型同时遵循 [人物与时尚造型](character-fashion.md)，交付结构见 [资产模板](prompt-templates.md)。

## 1. 用途与风格继承

先区分人物身份/服装设定图、场景空间参考图、MV 氛围效果图。未指定时，人物图和场景图优先用于身份、服装及空间确认；明确要求模拟成片风格时，再加入对应影像处理。不要求用户逐项确认这些内部判断。

共同视觉通过配色、服装、道具、空间形状和光线关系建立，不机械复制全片风格段落到每张资产。视频的颗粒、漏光、复古调色和运动模糊不自动继承到参考图。用户指定的插画、动画、非写实风格保留；清晰度规则不把所有项目改成写实摄影。

## 2. 清晰度、材质与风格

参考图默认成像清晰自然：主体边缘和细节可辨认，颜色层次明确，保留必要的空间纵深和真实材质，避免非预期的全图灰蒙、随机斑点、颗粒覆盖、色偏和过度锐化。写实资产可采用干净的数字摄影质感。

区分三个层次：

| 层次 | 内容 | 使用依据 |
|---|---|---|
| 实体材质 | 皮肤、织物、木纹、石材、锈蚀等物体自身特征 | 落在对应物体表面；保留项目需要且已确认的特征 |
| 环境状态 | 夜色、雾、雨、尘土等 | 有明确的时间、来源或范围；不能无依据覆盖主体 |
| 成像处理 | 胶片颗粒、噪点、漏光、复古调色、运动模糊等 | 默认不添加；用户明确要求或已确认视觉方案需要时，说明范围、强度与辨识要求 |

“电影感、写实、摇滚、乡野、先锋”等标签，不能单独作为增加颗粒、污渍、破损或泛黄的依据。材质真实不等于全图粗糙；不把“高清、8K、超细节”当作清晰度规则的替代。

保留已确认的风格处理，不能为了默认清晰而删掉用户要求的粗颗粒、雾气、暗部或做旧。尚未确认时，优先用造型、空间和光线表达项目气质，不自行把成片滤镜当成资产必需项。

## 3. 人物身份与服装设定图

未指定背景和照明时，采用无纹理的白色或中性浅灰背景、柔和均匀照明与自然色彩，优先看清五官和服装结构。用户指定背景、强侧光或氛围照明时尊重要求，按用途保证必要辨识度。

保持人物基础肤色；干净不等于提白或年轻化。保留适度皮肤肌理、清晰发丝和自然织物纹理，不主动增加污渍、粗糙皮肤、油光、斑点或磨损，也不通过重度磨皮消除身份特征。年龄与人物气质按项目设定，不默认套用清冷少年或单一审美脸型。

时尚表达优先通过廓形、比例、材质搭配、妆发与姿态实现。做旧若是已确认设计，限定在对应服装或道具部位，不能扩散成皮肤、背景和整幅画面的脏污感。

标准三视图包含全身正面、严格90度侧面、背面；同一人物、同一造型、等高比例、完整头顶和鞋底。默认姿态便于观察身体与服装结构，不用表演动作或持道具图替代侧面、背面。需要面部辨识时可另加大头像，称为“头像＋三视图”；只要求三视图时不强行加第四视图。用户指定其他角度或动作时按其要求标明实际视图。

已有参考不可见的结构需区分未知项与补充设计，不声称补充设计已经被参考锁定；用户禁止补充设计时，不强行重建不可见特征。正、侧、背的面部轮廓、发型体积、服装背部和配饰位置应一致。

## 4. 场景空间参考图

保留场景设定的时间、天气、地貌、材质和空间气氛，通过构图、光源、曝光和色彩层次保证空间可读。不因清晰度要求把夜景改为正午、旧建筑改成崭新建筑，或把所有表面磨平。

夜景可以保留暗部，旧建筑可以保留磨损，但关键通路、门窗、前后景和表演区域应能辨认。纹理落在对应物体表面：木纹属于木头，锈蚀属于金属，泥土属于地面；不把局部纹理扩展成全画面的脏点、灰雾或颗粒。

不因“旧粮仓、乡村、摇滚”等设定自动添加遍地垃圾、破损、尘雾、浓烟或污渍；需要时说明具体位置和创作作用。每张场景图有明确空间重点，装饰不遮挡关键结构；物件数量、连接与尺度合理。需要多个机位时保持同一场景的空间锚点和布置。

## 5. 提示词、检查与修订

每张资产分别写用途、主体/空间、构图、光线、必要材质、成像方式与保持项，按实际需要合并字段；不为填模板重复长篇风格要求。优先用正面描述明确目标，再补少量针对性排除项，避免同时要求颗粒做旧与无颗粒无做旧。

生成前检查：是否加入了没有依据的颗粒、做旧或色偏；是否把材质细节与图像噪点混为一谈；人物视图是否名实一致；场景光线是否保持原设定。

实际生成后查看身份与角度、服装结构、场景通路、细节层次、肤色与环境颜色，以及非预期颗粒或脏污感。多图项目逐张检查；只交付提示词时声明仅完成文本检查，不声称实际图像通过。

发现问题时只调整对应层：去颗粒不改脸；修正色偏不改基础肤色；清理非预期污渍不抹掉已确认的建筑或服装材质。一次修订针对最影响用途的问题，生成后再检查；没有具体未解问题时不反复重生成。

用户要提示词时按资产模板交付；用户要实际图片时使用当前可用的合适生图工具，查看已有参考，遵循工具的身份保持、编辑和保存要求。图像交付标明各图用途，提供可用的图片或保存位置，不强制附带完整 MV 提示词。
