# Prompt Templates

在交付完整提示词前读取。方括号为编写提示，正式交付必须全部替换或省略不适用部分。只输出当前模式所需模板，不让用户填写内部分析表。

先确定值得观看的段落，再用模板检查必要信息。相邻字段可以合并；与方案无关的字段直接省略。保留时间、主体、可执行的画面及声画衔接，不逐镜输出创作论证、导演百科或重复的全片规则。

时尚与先锋必须落实到画面和声音的具体选择，完整 MV、单场景与修订均须保留；除非用户明确改变定位，不得省略这一要求。内部状态表与质量门槛不随模板输出。

仅为实际存在且已查看的图片输出引用。纯文字原创时省略图片映射及“与图片一起提交”等说明，直接写已选角色、造型与场景；无人项目省略人物专用内容。下列模板中的图片数量和角色字段均按实际输入适配。

## 完整 30 秒 MV

```text
【目标与参考分工】
创作具有时尚表达与先锋形式实验的[时长、画幅]音乐 MV，面向[用户指定模型，默认 Seedance 2.5]。
@图片1：[辨识内容；负责的身份/场景/风格；必须保留与允许变化的范围]。
@图片2：[同上，按实际图片数继续]。
人物与场景关系：[现实、梦境、平行或连续；身份是否独立]。
[身份、服装、场景与风格分别采用的主参考；只说明实际存在的冲突及取舍]。
参考图支持场景内的新机位、景别和动作，不强制每图仅对应一个固定镜头。

【人物与时尚造型】
[有人物时：各角色编号与身份主参考、可见辨识特征、必要的未知项；明确原创时写已选结构，不伪造图片引用]。
[造型基线：妆容重点及色彩/落点/方向/质地、发型、服装廓形与材质、配饰位置；只写影响当前画面的内容]。
[主副气质如何通过视线、姿态、动作节律与摄影体现；造型如何参与全片视觉关系]。
[有允许的造型变化时写 Look 版本及切换时间；逐镜延续相应版本，光影变化不改身份；无人项目省略本节]。

【叙事、时尚与先锋视觉】
[一句叙事、情绪或形式推进；选定的段落结构及用户指定时点，不机械凑齐转折和高潮]。
[时尚表达：锁定服装与身份下，如何通过实际廓形、材质、身体姿态、比例和环境关系建立视觉张力]。
[主导先锋机制及相容的辅助手法：具体画面/声音关系、适用对象、必要的触发与保持项；用发展、持续、重复或中断形成全片联系，不要求每镜展示实验]。
[主辅色与强调色的作用、光源方向/软硬/反差、肤色与材质处理、构图及影像质感；跨场景保留项与允许变化项]。
[采用视觉母题时写其发展；当前项目应避免的具体风格偏差]。
[环境/人物关系、表演、细节、运动与停留的拍摄分工，只写当前方案需要的内容]。
[选定的观看位置、信息揭示或形式观看方式；多人物/复杂空间的必要站位、遮挡和行动顺序；导演风格转成具体摄影选择，简单方案与逐镜内容合并]。
[确有运镜标记时排除其出现在成片，实物线绳保留]。

【音乐、歌词与声音】
[音乐风格、BPM/拍号、主要音色、主唱身份、各段声部变化]。
[段落情绪、音乐密度与镜头快慢的关系；关键切点/动作与鼓点、停顿、drop、人声的对应关系]。
歌词：[逐句列起止时间、角色、原创新歌词、可见演唱或画外音；无歌词时明确]。
[动作声源、空间声学、人声与音乐/声效让位关系；需要声音跨场连接或有意声画错位时写范围与恢复点]。
全片声音连续，歌词跨镜头继续，不重启整首歌。

【逐镜编排】
镜头01｜[开始—结束秒]｜[观看任务、景别与机位；可简写]
[对象与开场构图]。
[有运动时写起点→路径/速度→结束构图；区分位移、转向、变焦和焦点转移。固定机位写画面组织或停留即可]。
[相关的人物位置/视线/遮挡与行动顺序；行动、演唱或有目的的静止及余势，环境/道具运动按需描述；简单镜头可合并为一句]。
[适用时写角色与造型版本、承接的持物手、朝向、动作阶段或实验状态；用画面体现本镜承担的时尚表达与先锋机制，不机械复述全片概念或身份基线]。
[本镜覆盖的歌词或拍点、同步声]。
[普通切镜写触发与关系；关键转场写结束构图→触发→下一镜起始构图、注意力落点与声音连接，并与下一镜描述一致]。

[按实际时长与镜头数继续，不能留省略号]。
[开场闪切可成组列出内部运动片段及时间，明确与主要镜头数的关系]。

【连续性与落版】
[各角色的身份、服装、数量、物理连接；特殊状态与允许活动的对象]。
[返回场景的时间关系与应延续/更新的动作、道具及环境状态；跨场景不融合；有意变化遵循已声明的先锋机制]。
[最终构图、可读时长、完成动作与环境余韵，和镜头表一致]。
[只针对当前素材的关键失败约束]。

【输出】
[一个明确的时长与画幅；镜头总数或主要镜头与内部闪切的明确计数；按需写帧率]。
[全片音乐、演唱与动作声一起输出；其他用户明确要求]。
```

## 单场景

```text
【参考与目标】
@图片1：[主体、身份、服装、道具与场景锁定]。
[指定时长、画幅、连续镜头或允许剪切]。
[有人物时写身份与造型基线、主副气质及允许变化项；固定人物不补造未知结构，纯文字原创不伪造图片标签]。

【时尚与先锋视觉】
[以现有廓形、材质、姿态和环境关系形成的时尚表达；色彩、光线、构图与影像质感的具体规则]。
[主导形式选择及表达目的；在镜内如何变化或持续，可由静止、重复和留白成立；必要的适用范围、触发和身份/空间保持项]。
[当前项目的具体风格边界；不为体现先锋强行增加剪切或更换服装]。

【摄影与表演】
[观看位置、起始机位与景别；有运动时给路径、速度与结束构图，变焦及焦点变化仅在实际采用时描述]。
[人物与前后景的必要关系、行动顺序或停留；采用行动/演唱时写起势与余势，道具和环境运动按需说明]。
[光源、前景、透视如何随拍摄位置改变]。
[固定机位可由画面关系、持续观看和声画对照成立，不强加动作；有箭头则说明仅作引导]。

【音乐与声音】
[风格、节奏、人声、歌词长度与分配、动作声与同步位置]。

【连续性与结束】
[实际存在的身份/数量/连接/标识/特殊状态风险]。
[结尾停留时间与继续发生的动作，符合用户要求]。
```

## 修订交付

代码块外简短说明改了什么、依据是用户反馈还是实际观看。随后按上述模式交付完整提示词，不能只给补丁段落。

内部核对：受影响模块及身份/造型/表现层 → 已确认的时尚表达/先锋机制与其他保留项 → 时间/歌词/转场/状态依赖 → 完整修订与质量门槛 → 下一次生成观察的 2–3 个现象。

## 成功样本的可迁移关系

用户报告效果较好的四图/20镜地下嘻哈样本提供以下参考，不代表此 Skill 已验证模型效果：

- 一图发展为不同任务：狗爪压入地毯的细节 → 犬群侧跟 → 人物运动揭示 → 稳定演唱 → 转头带动甩镜与尘雾转场。
- 动作触发剪辑：唱句落字 → 视线/转身 → 摄影机跟随 → 前景遮挡 → 下一场沿同方向出现。
- 快镜与稳镜互补：空间运动负责速度与揭示，稳定近景负责演唱、手势、材质，落版仍有举旗、喊唱和环境运动。
- 音乐骨架：96 BPM、4/4 的 12 小节等于 30 秒，四段各三小节是一种方案。其他风格重新分配，不继承此 BPM、数量或等长四幕。
- 不继承样本矛盾：统一镜头计数、歌词总表与镜头表时间、物体“触碰/未触碰”等状态。
