# hiccai-MV

将参考图或原创 MV 创意转成一份完整、可复制的音乐视频提示词。时尚表达与先锋创意是必须满足的创作方向，并落实到人物造型、摄影、表演、音乐和剪辑。

默认创作目标为 30 秒、Seedance 2.5；可按用户要求和平台实际能力调整。此仓库提供创作规则与模板，不包含视频生成服务，文本检查不能保证成片效果。

明确要求 MV 人物或场景参考图时，支持生图提示词；所在 Agent 有合适生图工具时可生成实际图片。资产默认清晰自然，区分实体材质、环境状态与成像处理；用户要求的颗粒、雾气、夜色或做旧按具体范围保留，不将成片滤镜自动套到所有参考图。

先设计观看体验，再安排人物调度与摄影，最后核对连续性并整理提示词。镜头方法库涵盖运镜、视角、空间关系、情绪组合与导演风格启发；按当前方案选用。时尚先锋在全片层面成立，允许静止、留白、重复和普通切镜，不要求每镜都展示特效或复杂运动。

## 使用

将仓库根目录作为完整 Skill 文件夹导入支持 Agent Skill 的工具，安装目录使用 `hiccai-mv`。展示名称为 **hiccai-MV**，调用标识为 **`$hiccai-mv`**。必须保留 `references/` 和许可文件；已有同名安装时保留本地修改。

上传参考图后输入：

> 使用 $hiccai-mv，根据这些图片创作30秒时尚先锋 MV，给我可与图片一起提交的完整提示词。人物身份保持一致，其余创作设定由你决定。

支持单场景、原创 MV 人物及局部修订，例如：

- “使用 $hiccai-mv，固定这张图的人物和服装，设计一个8秒连续镜头，以姿态和构图体现时尚先锋感。”
- “使用 $hiccai-mv，从零设计两位不同的成年角色和一支30秒 MV，以暖色、粗粝材质和身体节律形成先锋表达。只给提示词。”
- “使用 $hiccai-mv，只把主角唇色改成砖红，保留唇形、妆面光泽和其他设定，输出完整修订稿。”
- “使用 $hiccai-mv，为这支 MV 制作人物头像＋正侧背三视图和三张独立场景图；画面清晰自然，保留服装与建筑本身的材质。”

不同工具的安装与调用方式以其实际支持为准；也可以明确要求 Agent 读取根目录 `SKILL.md` 并沿文内链接读取所需资料。详细流程见 [使用指南](使用指南.md)。
