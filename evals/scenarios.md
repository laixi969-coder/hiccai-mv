# 行为复核场景

以下是人工或模型执行时使用的验收场景，不是已经运行的模型评测或成片通过报告。涉及参考图片时，执行者需提供相应真实素材；没有图不得假装观察。检查实际交付内容与约束，不按固定措辞打分。

| 场景与输入 | 关键通过条件 | 失败现象 |
|---|---|---|
| 固定人物：提供可见圆润轮廓、原有妆容与服装的人像；要求30秒清冷时尚先锋 MV，人物妆发服装不变 | 通过表演、光线、构图及主导实验实现方向；保留身份与造型 | 为清冷改尖下巴、加深眼窝、提白或新增实验妆 |
| 原创阵容：无图，设计两位不同成年角色，同款妆容，30秒暖色先锋 MV | 不伪造图片引用；角色结构有具体区别，同妆色彩/质地/方向/相对落点保持；一份完整 MV 提示词 | 每位角色一份独立人像提示词，换妆充当换脸，或阻塞要求上传并不存在的参考图 |
| 仅改唇色：已有完整方案，只将主角唇色改砖红 | 保留唇形、边缘、光泽、其他造型及无关镜头；原唇色参与匹配时只修正相关衔接 | 顺带丰唇、改变脸型或重写故事 |
| 观察局限：参考图闭眼或有强侧光，要求固定人物制作 MV | 可见特征、推测及未知项分开；不推断未知眼型或骨骼深度 | 将阴影写成确定的骨相，并在各镜强制重建 |
| 单镜头：固定服装与人物的8秒连续镜头，无歌词 | 镜内建立与发展时尚先锋关系；无额外切镜、歌词或自动生图 | 为展示机制增加多场景，或只有“先锋”标签 |
| 无人项目：仅产品和空间的12秒音乐片 | 跳过人物模块，以材质、空间、摄影和声画关系表达时尚先锋 | 无依据增加模特或妆容分析 |
| 回场与换装：已有两个允许的造型版本，规定18秒切换 | 切换前后身份不变，造型与镜头时间对应，回场不无故复位；过渡两端匹配 | 饰品换边、两套造型混穿、时间点与镜头表冲突 |
| 先锋与身份：使用镜像或时间错位但必须保持同一人 | 说明形式实验范围、触发、保持项与回应，明确影像表达和世界事件；不破坏口型 | 把漂脸、复制道具或口型错位直接解释成先锋 |
| 修复一致性：用户反馈回场后换脸，保留已确认创意 | 定位身份/造型/表现层，修复受影响模块及依赖；输出完整修订 | 删除时尚先锋目标、无依据承诺成片已修复 |
| 固定凝视：用户要求8秒固定机位，人物保持静止，通过空间和音乐体现时尚先锋 | 保留固定机位与静止，用构图、观看时长或声画对照成立；无需凑三段变化 | 自动加推镜、转身或抬手以满足“主动表演” |
| 运动接静止：侧跟人物后，在音乐停顿处接稳定近景 | 允许此组合，写清视线/注意力或反差作用，身份和时间连续 | 把运动接静态判成错误，强行继续移动 |
| 位移与变焦：指定机位固定、缓慢变焦至近景 | 保持摄影机位置，明确焦距和取景变化，不写穿越前景 | 用 Dolly in 代替 Zoom，要求前景视差随位移变化 |
| 多人长镜头：两位人物在12秒内先后进入前后景，镜头不中断 | 行动先后、遮挡、注意力转移与通路明确；允许镜内多个可完成的动作 | 机械执行“一镜一事件”拆开，或人物瞬间交换位置 |
| 导演启发：参考两种导演方向，生成30秒 MV | 选择主导观看语法及相容的反差，写成具体摄影和调度 | 每镜换导演标签，套用固定颜色情绪，附无依据名言 |
| 持续形式实验：同一动作重复，以最后一次停顿改变音乐关系 | 允许持续、累积与重复，保留时尚先锋方向，不要求每镜新事件 | 为凑起承转合不断加新场景、道具或效果 |
| 减法修订：用户反馈运镜过满、看不清服装，其他保留 | 减少竞争运动、调整观看距离和停留，保留身份及造型基线 | 增加更多技法、镜头或特效，宣称未生成的视频已改善 |

记录实际执行结果时附输入素材、完整提示词和观察依据；只有真实生成并查看视频后，才评价脸部保持、口型、镜头衔接或实际审美效果。

比较融合效果时，对同一输入分别使用历史版本与当前版本，保留同样的用户约束、执行模型与生成环境。先比较提示词能否执行、观看路径和节奏是否有区别；实际生成后再比较表现力、全片连贯性、服装/人物可读性与身份稳定。记录失败和随机波动，不按字数、术语数量或一次偶然成功判定升级有效。
